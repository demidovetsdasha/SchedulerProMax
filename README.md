# Парсер расписания Excel → Word (БГУИЯ)

Настольное приложение (macOS / Windows), которое переносит расписание из Excel
в Word по шаблону `templates/template.docx`.

## Порядок работы

1. **Открыть…** — выбрать Excel файл расписания (`.xlsx`, `.xls`).
   Факультет, курс и неделя берутся из имени файла, например
   `Расписание занятий ф-т нем.яз, специалист, очная (дневная), 3-й курс, 7-я неделя.xlsx`
   (факультет — текст после «ф-т » до запятой, курс — «3-й курс», неделя — «7-я неделя»).
   Поддерживается и старый формат `ф_т_ан_яз_спе_дн_2к_..._10_11_2025_16_11_2025.xlsx`.
   Если имя нестандартное, используется заголовок листа. Все поля можно исправить вручную.
2. Проверить **факультет**, **курс**, **даты недели** и **учебный год**
   (даты считаются по номеру недели из имени файла от `week1_monday` из конфига;
   учебный год подставляется по датам, его можно изменить). Год в «УТВЕРЖДАЮ» —
   текущий календарный год.
3. Собрать **страницы документа**: каждая страница — отдельная полная таблица
   со своей шапкой и подписями. Выберите страницу слева и отметьте её подгруппы справа
   (подгруппы, уже занятые на других страницах, помечены «(стр. N)»).
   «+ Страница» — добавить страницу, «Удалить» — убрать, «Авторазбивка» — разложить
   все подгруппы курса по страницам (до `max_columns_per_page` на страницу).
   Пустые страницы в документ не попадают.
4. **Сформировать Word** — выбрать, куда сохранить `.docx`. В журнале для каждой
   страницы указаны её подгруппы и подобранный кегль таблицы.

Объединённые ячейки Excel переносятся в Word один в один: по горизонтали (лекция на
несколько групп) и по вертикали (ячейка времени на 3 строки с тремя дисциплинами
по выбору, спаренные пары). В таблицу попадают только пары, в которые у подгрупп
страницы есть занятия. Кегль шрифта в таблице подбирается для каждой страницы так,
чтобы она поместилась на один лист (от `table_font_max_pt` до `table_font_min_pt`);
шрифт шапки и подписей не меняется.

## Конфигурация — `config/faculties.json`

| Поле | Назначение |
|---|---|
| `template` | путь к шаблону Word |
| `max_columns_per_page` | подгрупп на странице при «Авторазбивке» |
| `table_font_max_pt` / `table_font_min_pt` | пределы подбора кегля таблицы |
| `week1_monday` | понедельник 1-й учебной недели (для расчёта дат по номеру недели) |
| `head_ckop.name` | подпись начальника ЦКОП (В.Д.СИНЯК) |
| `faculties[].deputy_dean` | подпись заместителя декана факультета |
| `faculties[].header_name` | текст в шапке после «N КУРСА …» |
| `faculties[].aliases` | ключевые слова для автоопределения факультета по Excel |

После правки конфига нажмите **Перечитать конфиг** в приложении.

## Запуск из исходников

```bash
python3 -m venv .venv
# macOS:   source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Сборка в программу (.app / .exe)

Подробная инструкция для Windows — в [BUILD_WINDOWS.md](BUILD_WINDOWS.md).

Собирать нужно на той ОС, для которой нужна программа.

```bash
pip install pyinstaller
pyinstaller --noconfirm --windowed --name ScheduleParser main.py
```

Затем положите рядом с программой папки `config` и `templates`:

- Windows: `dist/ScheduleParser/` → `config/`, `templates/` рядом с `ScheduleParser.exe`
- macOS: `dist/` → `config/`, `templates/` рядом с `ScheduleParser.app`
  (или внутрь `ScheduleParser.app/Contents/MacOS/`)

Так конфиг остаётся доступным для редактирования без пересборки.
