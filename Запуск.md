## Запуск в терминале VS Code

1. Создать виртуальное окружение
```bash
uv venv --python 3.12 --system-certs
```

2. Установить необходимые библиотеки
```bash
uv pip install PySide6 python-docx openpyxl lxml xlrd --system-certs
```

3. Запустить в виртуальном окружении
```bash
.venv\Scripts\python.exe main.py
```

либо можно сначала активировать окружение и работать в нём как в обычном терминале:
```bash
.venv\Scripts\activate
python main.py
```
